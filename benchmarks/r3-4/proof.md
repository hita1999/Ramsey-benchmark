# R(3,4) — 下界と上界の証明

## C001: 8頂点の回避グラフが存在する

数学的状態: `PROVEN`。独立レビュー: `ACCEPTED`（`verification.md`参照）。

頂点集合を V={0,1,2,3,4,5,6,7} とし、次の10組だけを赤い辺、残りを青い辺とする。

```
03 05 14 16 25 26 27 36 37 47
```

各頂点の赤い近傍は次の通りである。

| 頂点 | 赤い近傍 |
|---|---|
| 0 | 3,5 |
| 1 | 4,6 |
| 2 | 5,6,7 |
| 3 | 0,6,7 |
| 4 | 1,7 |
| 5 | 0,2 |
| 6 | 1,2,3 |
| 7 | 2,3,4 |

どの行でも、近傍内の2頂点を結ぶ赤い辺は上のedge listに存在しない。
赤い三角形があれば、その1頂点の近傍内に赤い辺が存在するため、赤い三角形はない。

赤い辺を含まない三頂点集合 T は以下で全てである。
完全性は、最小頂点 a を固定し、a より大きい非近傍頂点から赤い辺を持たない2頂点を選ぶことで確認できる。

| 最小頂点 a | 独立な三頂点集合 T |
|---|---|
| 0 | 012, 017, 024, 046, 067 |
| 1 | 123, 135, 157 |
| 2 | 234 |
| 3 | 345 |
| 4 | 456 |
| 5 | 567 |
| 6,7 | なし |

上の近傍表を用いると、各 T について、T の頂点の赤い近傍の和集合はちょうど V \ T になる。
したがって T の外のどの頂点も、T の少なくとも1頂点と赤い辺で結ばれている。
独立な三頂点集合を四頂点に拡張できないので、青い K4 は存在しない。

## C002: R(3,4) ≥ 9

数学的状態: `PROVEN`。依存: C001。独立レビュー: `ACCEPTED`（`verification.md`参照）。

C001は8頂点上で両方の禁止構造を回避する彩色を与える。
それより少ない頂点への制限も両方を回避するため、Ramsey数の定義から R(3,4)>8、すなわち R(3,4)≥9 である。

ここまでがG001の下界証明である。以下の上界証明はC001/C002に依存しない。

## 上界で用いる定義

以下では任意の単純無向グラフを考える。辺を赤、異なる2頂点間の非辺を青と対応させる。
独立集合とは、その中の異なる2頂点がいずれも辺で結ばれていない頂点集合である。
したがって独立な4頂点は補グラフのK4、すなわち青いK4と同じ意味である。
頂点vの近傍N(v)はvと辺で結ばれる頂点の集合であり、次数d(v)はその大きさである。
自分自身を含まない非近傍を M(v)=V \ ({v} ∪ N(v)) と書く。
誘導部分グラフは、選んだ頂点と、それらの間に元から存在する全ての辺からなる。

## C003: 6頂点の三角形なしグラフは独立な3頂点を持つ

数学的状態: `PROVEN`。依存: なし。独立レビュー: `ACCEPTED`（`verification.md`参照）。

6頂点の三角形を含まないグラフHを取り、任意の頂点vを選ぶ。
N(v)内に辺xyがあるとv,x,yが三角形になるため、N(v)は独立集合である。

- d(v)≥3なら、N(v)から3頂点を選べば独立な3頂点が得られる。
- d(v)≤2なら、v以外の5頂点のうち少なくとも3頂点はvと隣接しない。
  その中から異なるa,b,cを選ぶ。Hは三角形を含まないので、a,b,cの3組全てが辺であることはない。
  非辺となる1組をx,yと書くと、vはx,yのどちらとも隣接せず、x,y間にも辺がない。
  よって{v,x,y}は独立集合である。

次数は整数なので、この2場合で全てを尽くす。
また、6頂点以上の三角形なしグラフでも、任意の6頂点に誘導される部分グラフへこの命題を適用できる。

## C004: 9頂点の回避グラフがあれば、その全頂点の次数は3

数学的状態: `PROVEN`（条件付き命題）。依存: C003。独立レビュー: `ACCEPTED`（`verification.md`参照）。

9頂点のグラフGが三角形も独立な4頂点も持たないと仮定する。
任意の頂点vについて、三角形がないことからN(v)は独立である。
独立な4頂点がないのでd(v)≤3である。

一方、もしd(v)≤2なら、|M(v)|=8−d(v)≥6となる。
M(v)に誘導されるグラフも三角形を含まないため、C003により、その中に独立な3頂点a,b,cがある。
M(v)の定義からvはa,b,cのいずれとも隣接しないので、{v,a,b,c}は独立な4頂点となり矛盾する。
したがってd(v)≥3であり、上の不等式と合わせてd(v)=3である。
vは任意だったので全9頂点について成り立つ。

## C005: 9頂点の任意のグラフに三角形または独立な4頂点がある。従って R(3,4) ≤ 9

数学的状態: `PROVEN`。依存: C004（およびその依存C003）。独立レビュー: `ACCEPTED`（`verification.md`参照）。

任意の9頂点グラフGを取る。三角形または独立な4頂点を持てば結論は成立する。
いずれも持たないと仮定すると、C004より全9頂点の次数は3であり、次数の和は9×3=27となる。

しかし次数の和を数えると、各辺は異なる両端の次数に1ずつ寄与するため、

    Σ(v∈V) d(v) = 2|E(G)|

である。右辺は偶数、27は奇数なので矛盾する。
したがって回避グラフは存在せず、9頂点の任意のグラフは三角形または独立な4頂点を持つ。
任意の赤青彩色に対し赤い辺だけからなるグラフへ適用すれば、赤い三角形または青いK4が存在する。
Ramsey数はこの性質を持つ最小の頂点数なので、R(3,4)≤9である。

## C006: R(3,4) = 9

数学的状態: `PROVEN`。依存: C002、C005。独立レビュー: `ACCEPTED`（`verification.md`参照）。

C002のR(3,4)≥9とC005のR(3,4)≤9を合わせるとR(3,4)=9となる。
下界を用いるのはこの結合段階だけであり、上界C003→C004→C005には下界証明書への依存はない。

C003〜C006はG002で作成した人間可読な証明であり、計算結果や外部定理を前提にしない。
C001〜C006の独立レビューはいずれもACCEPTEDである（`verification.md`参照）。

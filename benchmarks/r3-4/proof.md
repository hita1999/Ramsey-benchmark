# R(3,4) — 下界の証明

## C001: 8頂点の回避グラフが存在する

数学的状態: `PROVEN`。独立レビュー: `ACCEPTED`（`verification.md`参照）。

頂点集合を V={0,1,2,3,4,5,6,7} とし、次の10組だけを赤い辺、残りを青い辺とする。

```
03 05 14 16 25 26 27 36 37 47
```

各頂点の赤い近傍は次の通りである。

| 頂点 | 赤い近傍 |
|---|---|
| 0 | 3,5 |
| 1 | 4,6 |
| 2 | 5,6,7 |
| 3 | 0,6,7 |
| 4 | 1,7 |
| 5 | 0,2 |
| 6 | 1,2,3 |
| 7 | 2,3,4 |

どの行でも、近傍内の2頂点を結ぶ赤い辺は上のedge listに存在しない。
赤い三角形があれば、その1頂点の近傍内に赤い辺が存在するため、赤い三角形はない。

赤い辺を含まない三頂点集合 T は以下で全てである。
完全性は、最小頂点 a を固定し、a より大きい非近傍頂点から赤い辺を持たない2頂点を選ぶことで確認できる。

| 最小頂点 a | 独立な三頂点集合 T |
|---|---|
| 0 | 012, 017, 024, 046, 067 |
| 1 | 123, 135, 157 |
| 2 | 234 |
| 3 | 345 |
| 4 | 456 |
| 5 | 567 |
| 6,7 | なし |

上の近傍表を用いると、各 T について、T の頂点の赤い近傍の和集合はちょうど V \ T になる。
したがって T の外のどの頂点も、T の少なくとも1頂点と赤い辺で結ばれている。
独立な三頂点集合を四頂点に拡張できないので、青い K4 は存在しない。

## C002: R(3,4) ≥ 9

数学的状態: `PROVEN`。依存: C001。独立レビュー: `ACCEPTED`（`verification.md`参照）。

C001は8頂点上で両方の禁止構造を回避する彩色を与える。
それより少ない頂点への制限も両方を回避するため、Ramsey数の定義から R(3,4)>8、すなわち R(3,4)≥9 である。

これは下界のみの証明である。上界および正確な値は本成果では確定していない。

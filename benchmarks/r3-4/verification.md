# G002 独立レビュー結果

G002で追加された C003、C004、C005、C006 を、研究担当の自己監査とは独立に検証した。

## C003: 6頂点の三角形なしグラフは独立な3頂点を持つ

- 数学的状態: `PROVEN`
- 独立レビュー: `ACCEPTED`
- 発見経路から独立しているか: `YES`
- 残っている仮定・ギャップ: なし。

### 論理監査

任意の頂点 `v` について、三角形がないため `N(v)` は独立集合である。

- `d(v) >= 3` なら `N(v)` から3頂点を取れば独立3集合を得る。
- `d(v) <= 2` なら、残り5頂点中少なくとも3頂点 `a,b,c` が `v` と非隣接である。三角形がないため `a,b,c` の3組すべてが辺であることはできず、非辺 `xy` が存在する。`v-x`, `v-y`, `x-y` がすべて非辺なので `{v,x,y}` は独立3集合である。

次数は整数なので2場合で完全である。

### 独立な有限計算クロスチェック

研究担当のコードやG001の探索コードを利用せず、6頂点の単純グラフ全 `2^15 = 32768` 個を独立に列挙した。

- 三角形なしグラフ: 5,789個
- そのうち独立3集合を持たないもの: 0個

よってC003は有限計算でも確認された。

## C004: 9頂点の回避グラフがあれば全頂点の次数は3

- 数学的状態: `PROVEN`
- 独立レビュー: `ACCEPTED`
- 依存: C003
- 残っている仮定・ギャップ: なし。

三角形がないため任意の `v` の `N(v)` は独立集合である。独立4集合がないので `d(v) <= 3`。

一方 `d(v) <= 2` なら `|M(v)| = 8-d(v) >= 6`。`G[M(v)]` も三角形なしなのでC003からその内部に独立3集合 `{a,b,c}` が存在する。`M(v)` の定義より `v` は3頂点すべてと非隣接であり、`{v,a,b,c}` は独立4集合となって仮定に反する。

従って `d(v) >= 3`。上下を合わせて `d(v)=3`。`v` は任意なので全頂点に成立する。

必要条件を十分条件として扱う箇所はなく、C004が存在を主張していないことも確認した。

## C005: R(3,4) <= 9

- 数学的状態: `PROVEN`
- 独立レビュー: `ACCEPTED`
- 依存: C004（推移的にC003）
- 残っている仮定・ギャップ: なし。

三角形も独立4集合もない9頂点グラフが存在すると仮定すると、C004により全9頂点が3正則となる。その次数和は `9 * 3 = 27`。

一方、単純無向グラフでは各辺が両端の次数へ1ずつ寄与するため、握手補題を外部定理として引用する必要なく、直接

```text
Σ d(v) = 2|E|
```

が成り立ち、次数和は偶数でなければならない。27は奇数なので矛盾する。

従って9頂点の任意のグラフには三角形または独立4集合が存在し、赤辺をグラフの辺とする対応から `R(3,4) <= 9` が従う。

### 独立なSATクロスチェック

上の人間可読証明とは別経路として、9頂点36辺をBoolean変数とし、次を独立にSAT制約化した。

- 各3頂点集合について「3辺すべてが存在しない」制約（84個）
- 各4頂点集合について「6辺のうち少なくとも1辺が存在する」制約（126個）

合計210制約を独立なDPLL探索で検査し、充足不能であることを確認した。これはC005の結論と一致する。

この計算は補助的クロスチェックであり、C005の証明そのものは `proof.md` の理論証明だけで完結している。

## Mathematical work

Resume exactly the search represented by the Phase A checkpoint. Do not substitute a new algorithm before consuming the declared continuation unless the Phase A manifest explicitly encoded a pre-registered switch condition that has become true.

## Handoff PASS criteria

The operational handoff is `PASS` only if:

- fresh Phase B reconstructs state from Git without Phase A conversation history;
- no extra semantic instructions from the user are needed;
- checkpoint/config/code integrity validates;
- first research candidate index is exactly `2,000,000`;
- no Phase A research candidate is repeated;
- combined consumed research interval is exactly `[0,10,000,000)` if Phase B runs to budget;
- search semantics remain unchanged;
- any divergence/replay is separately accounted for;
- state/progress after resume is internally consistent and auditable.

The experiment may be operationally PASS even if no new mathematical certificate is discovered.
